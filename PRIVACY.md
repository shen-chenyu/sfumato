# Privacy

Photo decoding, resizing, curve fitting, tone reconstruction and exports run in your browser. Selected files are read through local object URLs and are never sent to an application server. There are no analytics, API keys, accounts, model downloads, or remote photo-processing services in the app.

The hosting provider receives ordinary requests for the page and its static assets, which can include standard request metadata such as IP address. External credit and GitHub links navigate to their respective providers only when followed.

The app stores only your language preference in local storage (`sfumato-language`). It does not persist photos or drawings across reloads. Download a PNG, SVG or recipe before closing. Recipes exclude the source photograph but contain vector marks that depict it, so share them with the same care as the drawing itself.

## 中文

图片解码、缩放、曲线拟合、明暗重建与导出均在你的浏览器本地完成。没有照片上传、统计分析、账号或远程图像处理服务。网站托管方仍会收到页面和静态资源的普通请求及其请求信息。外部来源和 GitHub 链接只有在点击时才会打开。

本地存储只保存语言偏好（`sfumato-language`），不保存照片或作品。刷新前请下载图片或配方。配方不含原照片，但保留描绘照片的曲线与明暗数据；它仍然能呈现照片内容。
