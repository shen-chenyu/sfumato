# Privacy

Photo decoding, resizing, stroke selection, playback and exports run in your browser. Selected files are read through local object URLs and are never sent to an application server. There are no analytics, API keys, accounts, model downloads, or remote photo-processing services in the app.

The hosting provider receives ordinary requests for the page and its static assets, which can include standard request metadata such as IP address. External credit and GitHub links navigate to their respective providers only when followed.

The app does not persist photos or drawings across reloads. Download a PNG, SVG or recipe before closing. Recipes exclude the source photograph but contain vector marks that depict it, so share them with the same care as the drawing itself.
