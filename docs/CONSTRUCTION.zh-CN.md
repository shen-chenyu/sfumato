# 显式曲线与调和明暗

[English](CONSTRUCTION.md)

Sfumato 的构造标准很具体：保存下来的配方，必须能在不读取原照片的情况下重画；修改构造，也必须真正改变图像。它处理二维图像边界，不识别人体器官，不恢复三维形状、材质或真实照明。

## 配方保存什么

每条亮度边界由一段或多段三次 Bézier 曲线组成。每段保存四个二维控制点（8 个数值），并在两侧各保存 3 个明暗样本（共 6 个）。另有 8×8 个明暗锚点，每个保存 x、y 和明暗值（共 192 个数值）。

因此保存数值总数为 `14 × 曲线段数 + 192`。共享端点在配方中重复保存，也被重复计数；这不是独立自由度。`recipeBytes` 单独统计包含元数据的紧凑 JSON 的 UTF-8 字节数。配方没有原照片或预存的密集图像，但曲线与明暗信息仍能描绘照片。

## 提取和拟合

原图按比例缩放到 160×160 画布，透明部分与留白合成为白色。缩小使用面积平均，放大使用双线性插值。平滑后计算梯度，通过非极大值抑制、滞后阈值和邻接图追踪边界链，去掉短链。边界按长度、平均对比度和宽泛的中心权重排序，保留最多 180 条，再拟合曲线。排序是启发式规则，不是语义判断或全局最优解。

拟合使用弦长参数化、端点切向估计和最小二乘。误差超出容差时递归分段，闭合链先拆分。默认容差是分析网格上的 0.8 像素；它衡量采样点与对应参数位置之间的误差，不保证真实连续边界的 Hausdorff 距离。相邻段共享端点，但不保证切向连续。

```
C(t) = (1−t)³P0 + 3(1−t)²tP1 + 3(1−t)t²P2 + t³P3
     = A0 + A1 t + A2 t² + A3 t³,  0 ≤ t ≤ 1

A0 = P0
A1 = 3(P1−P0)
A2 = 3(P2−2P1+P0)
A3 = P3−3P2+3P1−P0
```

界面的 x(t)、y(t) 直接来自当前控制点。显示保留三位小数，配方保留完整精度。移动端点时，同链内已经连接的邻段端点及其相邻控制柄一起移动，保持原有的位置连接。

## 明暗重建

沿曲线采样，在其法线两侧约 1.65 分析像素处放置保存的明暗约束；样本沿曲线插值。重合样本加权平均，锚点权重 0.7、曲线样本权重 1。约束点固定，其余网格点满足离散调和条件：

```
u(x,y) = 相邻有效网格点的平均值
```

图像外侧不增加虚构邻点。求解采用红黑顺序的超松弛迭代，松弛系数 1.75。默认最多 500 次，最大更新量低于 1e−5 时停止。`stats` 报告最大更新量、调和残差、迭代次数与停止状态。达到迭代上限时仍返回当前近似结果，不声称已经收敛。

自由网格点和邻接关系在单次求解中不变，因此预先缓存，减少循环中的重复判断。缓存保持原来的更新顺序和算术顺序；回归测试对照优化前的像素与求解统计。卡片计数和曲线路径也只计算一次后复用。

## 如何理解输出

纯曲线 SVG 展示几何；160×160 RGBA 图像展示求解的明暗；数学自画像卡片把曲线、真实计数和一段方程放在一起。放大显示不会增加照片细节。示例曲线按近似弧长选择较长的非直线段，不等于“最重要的人体曲线”。

这些数字适合回答“这张照片，被当前算法写成了多少数学”。它们不衡量一个人的复杂度或颜值，也不证明这是最简或完美的数学构造。复杂背景、光照、头发和照片尺寸都会影响边界提取及计数。
